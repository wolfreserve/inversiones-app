# Inversiones (versión de prueba)

App personal para ver el **valor intrínseco** y el **valor justo** de las acciones del portafolio.
Se instala en el iPhone desde Safari (Compartir → Agregar a pantalla de inicio).

- 13 modelos de valoración tomados de Morningstar, GuruFocus, InvestingPro, Simply Wall St y Alpha Spread.
- `data.json` se actualiza el día 20 de cada mes con los últimos resultados, precios, tasas y noticias; cada cambio queda en el historial.
- No guarda datos personales: los ajustes que hagas se quedan en tu teléfono.
